## PikPak 是什么？先搞清楚它跟普通网盘的区别

PikPak 的核心玩法叫做**云下载**，或者叫离线下载。

你把一个磁力链（Magnet）、BT种子、HTTP 直链，甚至 X（原 Twitter）上的视频链接丢给 PikPak，它的服务器拿到任务之后，自己在云端把文件下载下来，存到你的私密云盘空间里。

你不需要等它下载完，直接关掉浏览器，它后台自己跑。过一会儿打开一看，文件已经好好躺在那里了。

这跟你在自己电脑上开迅雷是完全不同的逻辑——**你的宽带根本没有参与下载过程**，速度取决于 PikPak 服务器，不是你家网速。所以哪怕你是 10M 小水管，也可以秒存一部 4K 高清电影。

存好了之后，再通过 PikPak 客户端或者**网页版**直接在线播放，或者慢慢下到本地。

## PikPak 网页版核心操作：怎么添加磁力链和离线下载任务？

这是很多人最关心的使用场景。

在 PikPak 网页版主界面，找到页面左上角或中间区域的**"+"号按钮**（或"添加"按钮），点击之后会出现一个输入框。

把你的磁力链（格式类似 `magnet:?xt=urn:btih:...`）、BT 种子链接、或者普通 HTTP 下载链接直接粘贴进去，点确认。

PikPak 服务器就接手了。你不需要等，直接关掉页面，等过一段时间（热门资源通常几秒钟，冷门资源可能几分钟到几十分钟）再回来看，文件就下好了。

**支持的链接类型：**
- Magnet 磁力链
- BT 种子文件（也可以直接拖入浏览器）
- HTTP/HTTPS 直链
- ED2K 链接
- X（Twitter）视频分享链接
- 其他社交媒体视频链接

## 几个使用 PikPak 网页版的小技巧

**1. Chrome / Edge 浏览器体验最佳**

网页版在主流 Chromium 内核浏览器下运行最稳定，建议用 Chrome 或 Edge 访问。

**2. 添加任务后不需要一直盯着看**

云下载任务是服务器端执行的，你完全可以关闭浏览器页面去干别的，下好了再来看。

**3. iPhone 用户必备的工作流**

iOS App 无法添加磁力链，所以固定工作流可以是：手机浏览器打开 PikPak 网页版添加任务 → 等待完成 → 打开 iOS App 播放。

如果你是会员，可以在网页版设置里开启 WebDAV，然后用 Infuse（iOS）、Kodi（跨平台）或其他支持 WebDAV 的播放器挂载 PikPak，实现更强大的媒体中心体验。
